== What is "Caelum"?
Caelum is a kernel that sits between UNIX v6/v7 and xv6 made with C and NASM! Read more details in: link:PHILOSOPHY.adoc[PHILOSOPHY]

=== "Seriously, isn't world already fill with Unix-like kernels?"
Yes, the world already has a lot of Unix-like kernels and I'm not trying to say this is special, it's just a hobby kernel I created.

=== "Why the name 'Caelum'?"
It is a reference and a pun for link:https://en.wikipedia.org/wiki/Inferno_(operating_system)[Inferno made by Bell Labs.]

[NOTE]
Caelum means "Sky" or "Heaven" in Latin.

=== "Did you use AI?"
Yes, i used AI to make this but i did not "vibe-code", i tested it, i ran though GDB.

[NOTE]
Vibecode may have different meaning for some people, but for me, it means "blindly trust AI."
