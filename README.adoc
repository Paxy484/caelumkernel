== What is "Caelum"?
Caelum is Kernel that sits between UNIX v6/v7 and xv6 made with C and NASM! See more detailed in: link:PHILOSOPHY.adoc[PHILOSOPHY]

=== "Seriously, inst world already fill with Unix-like kernels?"
Yes, the world already has a lot of Unix-like kernels and i'm not trying saying this is special, it's just hobby kernel i created

=== "Why the name 'Caelum'?"
It reference and pun for link:https://en.wikipedia.org/wiki/Inferno_(operating_system)[Inferno made by Bell Labs.]

[NOTE]
Caelum means "Sky" or "Heaven" in Latin.

=== "Did you use AI?"
Yes, i used AI to make this but i did not "vibe-code", i tested it, i run though GDB.

[NOTE]
Vibecode may have dirffent meaning for some people, but for me, it means "blindly trust AI."
